
# 🚀 Version Control System - Git

## 📌 Introduction
**Git** is a **Distributed Version Control System (VCS)** used to track changes in source code and files during software development. It helps developers collaborate efficiently, manage project history, and restore previous versions when needed.

🔗 Official Website: https://git-scm.com

---

# ✨ Why Git is Important

✅ Tracks project changes  
✅ Helps in team collaboration  
✅ Maintains complete project history  
✅ Allows rollback to previous versions  
✅ Supports branching and merging  
✅ Widely used in software industries

# 📂 Git Workflow

```bash
Working Directory → Staging Area → Local Repository → Remote Repository

🛠 Common Git Commands
🔹 Initialize Repository
     git init
Creates a new Git repository.

🔹 Check Status
git status

Shows modified files and current status.

🔹 Add Files
git add filename

Add specific file.

git add .

Add all files.

🔹 Commit Changes
git commit -m "Initial Commit"

Saves project changes.

🔹 View Commit History
git log

Displays commit history.

🔹 Create Branch
git branch feature-name

Creates a new branch.

🔹 Switch Branch
git checkout feature-name

Moves to another branch.

🔹 Merge Branch
git merge feature-name

Combines branches.

🔹 Clone Repository
git clone repository_url

Copies repository from GitHub.

🔹 Push Changes
git push origin main

Uploads code to GitHub.

🔹 Pull Latest Changes
git pull origin main

Downloads latest updates.
